# 中医新药组方量化模型（代谢综合征·痰核心）

针对代谢综合征、以「痰」为核心病机的中医组方量化探索工具。内置化痰及相关药物评分库，通过证候参数实时计算，输出君臣佐使、剂量、剂型与方解建议。

> 评分依据《中药学》教材与药典常识拟定，仅供科研组方探索，**不构成临床用药指导**。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址即可。项目为纯前端应用，无需后端。

## 模型思路

1. **病机核心**：代谢综合征在中医常归痰浊、脾虚生痰、痰瘀互结等；本工具以「痰」为主轴，并叠加脾胃、寒热与代谢侧重。
2. **药物量化**：每味药给出化痰力度、痰型适配（寒/热/湿/燥）、四气、脾胃、降脂/降糖/化浊、剂量与剂型适宜度等分数。
3. **单药综合分**：

   `score = (w1·化痰匹配 + w2·脾胃 + w3·寒热校正 + w4·代谢) / Σw`

   - 化痰匹配 = 化痰力度 × 痰型适配加权 × 痰浊程度加成
   - 寒热校正 = 药性与患者寒热的互补程度（热证喜寒药）
4. **组方规则**：按得分排序，套用君臣佐使（约 6–10 味），校验十八反十九畏类禁忌，微调全方寒热平衡，再建议剂量与剂型。
5. **基础方锁定**：可锁定「竹沥 + 陈皮 + 红曲」，由模型补齐配伍。

## 界面说明

| 区域 | 功能 |
|------|------|
| 组方计算 · 左栏 | 证候滑块、权重、预设模板、基础方锁定 |
| 组方计算 · 右栏 | 君臣佐使卡片、寒热仪表、剂型、方解、警示 |
| 药物库编辑 | 浏览/搜索药物，在线改评分，自动写入 localStorage |

## 关键文件

- `src/data/herbs.json` — 药物量化库（约 45 味）
- `src/data/presets.ts` — 证候预设模板
- `src/engine/formulate.ts` — 组方引擎
- `src/components/*` — 输入、结果、药物库编辑 UI
- `src/hooks/useHerbStore.ts` — 药物库本地持久化

## 评分字段约定

| 字段 | 范围 | 说明 |
|------|------|------|
| phlegmForce | 0–10 | 化痰力度（如半夏 10、陈皮 9） |
| phlegmAdapt.* | 0–10 | 对寒/热/湿/燥痰的适配 |
| nature | -3–+3 | 四气（大寒…大热） |
| spleenStomach | 0–10 | 健脾和胃 |
| metabolic.* | 0–10 | 降脂 / 降糖 / 消食化浊 |
| formSuit.* | 0–10 | 汤/颗粒/丸/膏适宜度 |

可在「药物库编辑」中直接修改；「恢复默认」可清空本地改动。
